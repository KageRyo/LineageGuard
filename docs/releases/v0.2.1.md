# LineageGuard v0.2.1

This patch moves Linux x64 release builds to Ubuntu 24.04 and keeps the documented glibc 2.34 minimum runtime requirement.

## Changes

- Build the Linux x64 release archive on Ubuntu 24.04.
- Reject Linux binaries that require GLIBC symbols newer than 2.34, then smoke-test the built binary in an Ubuntu 22.04 container before packaging.
- Document the Linux x64 runtime requirement as glibc 2.34 or newer.
- Keep the Windows x64 and macOS ARM64 release targets unchanged.
