# LineageGuard v0.3.1

This patch rebuilds the CLI with serde_json 1.0.154 and sha2 0.11.1. Manifest validation, artifact hashes, lineage comparison and command output contracts are unchanged.

The release keeps the existing Linux x64, Windows x64 and macOS ARM64 archives, SHA256SUMS verification and Linux glibc 2.34 baseline.
