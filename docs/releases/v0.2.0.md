# LineageGuard v0.2.0

LineageGuard v0.2.0 adds graph exports, a checksum-verified GitHub Action, and consistent standalone binary archives.

## Changes

- Add `lineageguard graph` with Mermaid output by default and optional Graphviz DOT output.
- Include all declared source and artifact nodes, including isolated nodes, while preserving source availability and input-to-artifact edge direction.
- Add the `KageRyo/LineageGuard@v0.2.0` composite Action for Linux x64. It runs `validate` and `verify` after verifying the downloaded archive against `SHA256SUMS`.
- Publish Linux x64, Windows x64, and macOS ARM64 archives with license notices and a release-wide `SHA256SUMS` file.

The Action does not run `audit`; provenance gaps remain an explicit CI policy choice.

## Publication acceptance

The tag workflow creates or updates a draft release. After publishing that draft, run the documented Action from a clean consumer workflow and confirm it downloads the Linux archive, verifies its checksum, and passes both `validate` and `verify`. Local Action fixtures exercise the wrapper with a fake binary and do not replace this post-publication check against the real release asset.
