# LineageGuard v0.3.0

LineageGuard v0.3.0 adds deterministic manifest comparison for local review and CI summaries.

## Changes

- Add `lineageguard diff OLD NEW` to compare sources, artifacts, and lineage edges between two manifests.
- Show added and removed entities with their declared fields, changed entities with field-level old and new values, and edge additions or removals.
- Support deterministic text and JSON summaries, including manifest schema version changes.
- Add `examples/manifest-diff/` with two synthetic manifest versions.
- Keep comparisons offline and manifest-only; the command does not read payload files or verify their hashes.
